# Contributing

Contributions should preserve the project's narrow, evidence-led scope.

- Reproduce a change on hardware you own or are authorized to modify.
- State the full build fingerprint and whether the result was read-only or
  device-changing.
- Never submit credentials, unique device identifiers, firmware dumps, OEM
  applications, or proprietary service material.
- Add a rollback and explicit stop condition for every device-changing step.
- Do not broaden support from a model name or chipset alone.
- Keep account, subscription, DRM and activation bypasses out of scope.

When adding support for a new firmware, create a separate profile and fixture.
Do not edit the existing verified profile to accept both variants.
